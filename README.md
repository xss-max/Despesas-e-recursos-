# 💰 Finanças em Família

Aplicativo web progressivo (PWA) e mobile para controle financeiro familiar, faturas de cartão de crédito, saldo bancário e assinaturas mensais.

## 🚀 Como rodar localmente

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento
npm run dev
```

## 📱 Como usar no celular

1. Acesse o link publicado no GitHub Pages pelo navegador do celular (ex: Google Chrome).
2. Toque no menu do navegador (três pontinhos).
3. Selecione **"Instalar aplicativo"** ou **"Adicionar à tela inicial"**.
4. O app será instalado no seu aparelho e funcionará como um aplicativo nativo.
